СЮДА ПОЛОЖИ ФОТОГРАФИИ (jpg, png, gif, webp — любые имена и размеры).

Сайт сам найдёт их и построит "водопад" на второй странице.

Важно: чтобы сайт увидел фото, открывай его через сервер:
 - в VS Code: расширение "Live Server" → ПКМ по index.html → "Open with Live Server"
 - или в терминале: python -m http.server  →  открыть http://localhost:8000

Если не хочешь возиться с сервером — перечисли файлы вручную
в массиве FALLBACK_IMAGES в начале скрипта в файле summer.html.
